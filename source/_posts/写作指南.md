这篇文件本身就是模板。你新建文章后照着改就行，不需要时整篇删掉。

## 新建文章

```bash
npx hexo new post "文章标题"
```

会在 `source/_posts/` 下生成 `文章标题.md`，同时在旁边生成一个**同名文件夹**。这个文件夹就是这篇文章的图片仓库。

## 放图片的两种方式

**方式一：跟文章一起走（推荐，图片少时用）**

把图片丢进同名文件夹，然后正文里直接写文件名：

```markdown
![图片说明](cover.png)
```

不用写路径，不用管目录层级，渲染时会自动解析成正确地址。

**方式二：公共图片库（多篇文章复用同一张图时用）**

图片放 `source/images/`，正文按站内绝对路径引用：

```markdown
![图片说明](/images/common/logo.png)
```

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npx hexo new post "标题"` | 新建文章 |
| `npx hexo new page "about"` | 新建独立页面（如关于我） |
| `npx hexo server` | 本地预览，改完刷新即见 |
| `npx hexo generate` | 生成静态文件到 `public/` |
| `npx hexo clean` | 清缓存，样式不生效时先跑这个 |

本地预览时改 Markdown 会自动热更新，改主题配置需要重启 server。

## 关于 Markdown 语法

标准语法全部支持，另外这些也能用：

- 任务列表：`- [x] 已完成` / `- [ ] 待办`
- 表格、脚注、代码块高亮
- 数学公式：行内 `$E=mc^2$`，独立成段用两个美元符号包裹
- 折叠：用 `<!-- more -->` 之前的正文会作为首页摘要
